# Dead Grid

Dead Grid is a browser-based 2D pixel zombie survival prototype.

## Play

Open `index.html` in a browser.

## Controls

- `W`, `A`, `S`, `D`: move
- Mouse: aim
- Left click: shoot
- `R`: reload
- `E`: loot nearby crates and drops
- `F`: toggle flashlight
- `Shift`: sprint
- `Ctrl`: crouch
- `Space`: jump
- `1`, `2`, `3`: switch weapons
- `B`: collapse or expand the tech tree
- `Esc` or `P`: pause

## Features

- Proximity-based zombie awareness
- Safe starting zone
- Loot crates, drops, ammo, scrap, XP, and leveling
- Wood, parts, and better loot icons
- Procedural farms, cabins, survivor camps, depots, clinics, and radio towers
- Objective chain that encourages exploration and returning to base
- Upgradeable base camp with expanding safe-zone stages
- Upgradeable tech tree
- Save, load, new game, and quit-to-menu flow
